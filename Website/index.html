Texture Optimizer

English guide · 한국어 설치 안내 · 日本語インストールガイド

Inspect texture memory and apply reversible resolution-cap reductions. Unity UI (com.unity.ugui) required. Editor-only: no runtime or network hooks.

Made for VRChat projects using Unity 2022.3.22f1. Other Unity versions have not been tested and may be incompatible.

Install with VRChat Creator Companion

Add repository to VCC

Then manage your project in VCC and add prokjs Texture Optimizer.

Or add this repository URL manually in VCC Settings → Packages → Add Repository:

https://prokjs.github.io/texture-optimizer/index.json

Other installation options

  • Download v1.0.0 .unitypackage. Ensure Unity UI is installed, then import into your project.
  • Unity Package Manager → Add package from git URL: https://github.com/prokjs/texture-optimizer.git#v1.0.0.
  • Download the VPM package ZIP (package contents at archive root).

Use only one installation method per project. Back up your project before changing texture settings.

Open Tools → prokjs → Texture Optimizer in Unity.
